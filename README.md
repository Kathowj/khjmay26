khjmay26 is a number guessing game. 

The number picking program selects a number between 1-100 and then asks the user to guess that number. 
The user responds with a guess and enters a number between 1-100. 
The program then tells the user if the guess is too high or too low and then provides the user
another opportunity to guess the selected number. This iterative process continues until the 
user guesses the selected number correctly.
